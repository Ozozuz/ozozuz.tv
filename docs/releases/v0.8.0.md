# v0.8.0 — My memory now has tabs

- New launcher/home mascot based on the supplied lilac-haired cat character, waist-up with a closed dark shirt.
- Local favourites for films and series, a dedicated home tab, and local search/type filters. Saved posters follow catalogue-domain changes.
- Whole-season downloads: choose a folder, export sequential MP4s, skip completed files, cancel or resume the remaining queue after interruption. Stream links are resolved freshly per episode.
- In-app Download library grouped by show/season, with offline playback, watched marks, storage sizes and deletion. Existing 0.7.0 file records are recognized without re-downloading.
- 54 JVM tests and Android SDK build. Native source resolution verified against real video/audio manifests; no full on-device season download or UI test.

**Signing note:** this test APK uses a new development key because the old key was lost during workspace cleanup. It cannot update the old installed APK. Recover the original key to preserve that installation and its local data; do not uninstall it as a workaround if those data matter.


The delivered **preview** installs alongside the old app as `ozozuz.tv (test)` using package `it.reozoz.streamclean.preview`, with separate data. It does not overwrite or migrate the old installation. Normal source builds retain the original package; `SC_PREVIEW=1` selects the preview in the SDK build script.
