# v0.6.0 — The thumb is now a managed endpoint

First repository release of the current Android app. Native catalogue, real
catalogue search, film/series details, season grid, episode thumbnails and
embedded playback are all present.

The interface now uses black/graphite panels, monospaced headings, fine borders
and restrained green accents. The series background has learned to use its
indoor voice.

The player retains the 0.5.1 height adjustment: a 16:9 width calculation plus
56 dp of control clearance, with a 260 dp minimum for series playback.

- Android 8.0 / API 26 or later.
- Package: `it.reozoz.streamclean`; installed name: `StreamClean`.
- Version: `0.6.0` / versionCode `8`.
- Included APK is the existing verified build, with the same development signer.
- Android SDK compilation, alignment and v2/v3 signature verification passed.
- 21 JVM regression tests passed. Latest visual layout still needs phone testing.

Known limits: first search-results page only, no accounts/offline downloads,
manual domain changes, provider-dependent playback. See the README for details.

The app cannot make the source website trustworthy. It can, however, stop me
from treating every glowing rectangle as a legally binding invitation to tap.
